# חנות „חמש” – מדריך קצר

החנות יושבת בכתובת `/shop/` באתר, וכתובה ב־HTML, CSS ו־JavaScript רגילים, בלי שלב בנייה ובלי תלויות.
כל המוצרים, הקטגוריות וההגדרות נמצאים בקובץ אחד: `shop/assets/catalog.json`.

## מה יש בחנות

- **5 קטגוריות** עם 6 מוצרים לדוגמה בכל אחת (30 מוצרים).
- **עמוד בית**: באנר ראשי, יתרונות, אריחי קטגוריות, מוצרים נבחרים, פס מבצעים, קוד קופון ושאלות נפוצות.
- **עמודי קטגוריה וכל המוצרים**: סינון (מבצע, חדש, במלאי), מיון, ומעבר מהיר בין הקטגוריות.
- **עמוד מוצר**: גלריה, בחירת צבע או מידה, כמות, מלאי, מועדפים, מוצרים דומים, ופס הוספה לסל שנצמד לתחתית המסך בנייד.
- **חיפוש** עם תוצאות תוך כדי הקלדה. החיפוש מבין עברית: „ספלים” ו„הספל” מוצאים „ספל”, „עגילים” מוצא „עגילי חישוק”, וניקוד ואותיות סופיות לא משנים.
- **סל קניות** (מגירה צדדית ועמוד מלא), קופון, ופס התקדמות למשלוח חינם. המשלוח החינם נבדק לפני הנחת הקופון, כך שקופון לא מבטל אותו.
- **קופה** בעמוד אחד, עם בדיקת שדות, תיקון טעויות במייל (gmial → gmail), טיוטה שנשמרת, ואיסוף עצמי.
- **עמודי מידע**: אודות, צור קשר, שאלות נפוצות, משלוחים והחזרות, תקנון, פרטיות והצהרת נגישות.
- כתובות נקיות (`/shop/home/linen-cushion`), נתוני Schema.org למוצרים, ונגישות לפי ת״י 5568.

## איך מחליפים מוצרים

ב־`catalog.json`, תחת `products`, כל מוצר נראה כך:

```json
{
  "id": "p101",                 // מזהה קבוע, לא משנים אחרי שהחנות באוויר
  "slug": "linen-cushion",      // החלק בכתובת: /shop/home/linen-cushion (אותיות לועזיות קטנות ומקפים)
  "cat": "home",                // ה־slug של הקטגוריה
  "name": "כרית פשתן רכה",
  "price": 149,                 // בשקלים, כולל מע״מ
  "compareAt": 189,             // לא חובה: מחיר קודם אמיתי (חובה לפי חוק שיהיה אמיתי)
  "short": "שורה אחת לכרטיס המוצר",
  "desc": "תיאור לעמוד המוצר",
  "details": ["חומר", "מידות", "הוראות כביסה"],
  "tags": ["new", "sale", "best"],   // חדש / מבצע / רב מכר
  "options": { "name": "צבע", "values": ["חול", "זית"] },   // לא חובה
  "stock": 12,                  // לא חובה. 0 = אזל מהמלאי
  "featured": true,             // מופיע ב„הנבחרים שלנו” בעמוד הבית
  "images": ["/shop/assets/img/products/linen-cushion-1.webp"]
}
```

הערות (`//`) הן רק להסבר כאן. בקובץ האמיתי אסור לכתוב אותן.

- **תמונות**: שמים את הקבצים ב־`shop/assets/img/products/` ומוסיפים את הנתיב ל־`images`. מומלץ WebP ביחס 4:5 (למשל 1200×1500). כל עוד `images` ריק, מוצג איור לדוגמה בצבע הקטגוריה.
- **קטגוריות**: תחת `categories`, אפשר לשנות שם (`name`), תיאור (`blurb`, `intro`), גוון (`hue` מ־0 עד 360) ואייקון (`home`, `cup`, `drop`, `bag`, `gift`).
- **הגדרות החנות**: תחת `store`, שם החנות, טקסט הבאנר, משלוח חינם מ־(`freeShippingFrom`), שיטות משלוח ותשלום, קופונים ופרטי קשר. כל עמודי המידע מתעדכנים מכאן אוטומטית.
- **צבעים**: בראש `shop/assets/css/shop.css`, תחת `:root`. הצבע הראשי הוא `--accent`.

## הזמנות במייל

בלי הגדרה, הקופה פותחת **וואטסאפ** עם הודעה מוכנה שמכילה את כל פרטי ההזמנה, ושולחת אותה למספר שב־`store.contact.whatsapp`. כך החנות עובדת מהיום הראשון.

כדי לקבל את ההזמנות במייל (דרך [Resend](https://resend.com)), מגדירים ב־Vercel (Settings → Environment Variables):

| משתנה | |
|---|---|
| `RESEND_API_KEY` | חובה |
| `ORDER_TO` | חובה: הכתובת שמקבלת את ההזמנות (אם לא מוגדר, משתמשים ב־`CONTACT_TO`) |
| `ORDER_FROM` | לא חובה: כתובת שולח מדומיין מאומת ב־Resend |
| `ORDER_CUSTOMER_COPY=1` | לא חובה: שולח גם ללקוח מייל אישור. עובד רק עם `ORDER_FROM` מדומיין מאומת |

מרגע שהמשתנים מוגדרים, הקופה שולחת לשרת, והשרת **מחשב מחדש את המחירים מהקטלוג**, כך שאי אפשר לשנות מחיר מהדפדפן. גם הרשמה לניוזלטר בעמוד הבית נפתחת רק כשהמייל מוגדר.

**תשלום באשראי באתר**: כרגע התשלום נגבה בטלפון או ב־bit אחרי אישור ההזמנה. כדי לגבות כבר באתר צריך לפתוח חשבון אצל ספק סליקה (למשל Cardcom, Tranzila, PayPlus או Grow), ואז לחבר את עמוד התשלום שלו לקופה.

## לפני שהחנות עולה לאוויר

- [ ] להחליף את המוצרים, המחירים והתמונות באמיתיים. מחירי `compareAt` חייבים להיות מחירים קודמים אמיתיים, ותגית „רב מכר” רק למה שבאמת נמכר הכי הרבה.
- [ ] למלא ב־`store.contact` טלפון, וואטסאפ, מייל, כתובת העסק (`address`), נקודת איסוף ורכז/ת נגישות.
- [ ] בעמודי המידע (`shop/assets/js/pages.js`) למלא את כל מה שבסוגריים מרובעים, כמו `[מספר עוסק / ח.פ.]`.
- [ ] **שעורך/ת דין יעברו על התקנון, מדיניות הפרטיות ועמוד המשלוחים וההחזרות.** הם נכתבו בזהירות, אבל הם טיוטה.
- [ ] להסיר את `<meta name="robots" content="noindex">` מ־`shop/index.html` ולהוסיף את `/shop/` ל־`sitemap.xml`.
- [ ] להגדיר את משתני המייל (למעלה) ולשלוח הזמנת ניסיון.

## בדיקות

```bash
node --test shop/tests/
```

הבדיקות מכסות את חישובי המחיר, את שרת ההזמנות ואת ההרשמה לניוזלטר. הן גם בודקות שהדפדפן והשרת מחשבים בדיוק אותו סכום.
